Code to document the analysis process and figures created for the manuscript "Cis-acting long non-coding RNAs as early phase drivers of vascular smooth muscle cell activation"

Input files created from steps prior to the R documentation are not included but are available upon request, namely:
- GTF files for the bespoke annotation
- RSEM outputs for gene-level and transcript-level counts
- PLAR outputs indicating transcript-level coding or non-coding status

Full details to recreate all aspects of the analysis are supplied in the methods section of the paper

Recreation of figures used in paper can be done with the files contained in inputs

Scripts to make figures are as follows
- Fig1: scripts/PT-1-DEG-ANNOTATION-EARLY-PHASE/PT1-4 Biotypes_DE_patterns.R
- Fig2: scripts/PT-2-CISLNC-EARLY-PHASE-RNASEQ/PT2-8 LncRNA_cis_subtype_timeBias.R and scripts/PT-2-CISLNC-EARLY-PHASE-RNASEQ/PT2-9 PCG_Comparison_CoRegulation.R
- Fig3: scripts/PT-3-CISLNC-EXTERNALDATA-OVERLAP/
- Fig4: scripts/PT-4-INFLUENTIALLOCI/
- Fig6: scripts/TBA
- Fig7: scripts/PT-5-OTHER-TIMECOURSES
